# AI Document Analyzer (Fullstack MVP) 

Современное Fullstack-приложение для интеллектуального анализа, структурирования и суммаризации текстовых документов с помощью большой языковой модели (**GigaChat LLM**). Проект позволяет пользователю загружать файлы различных форматов, получать очищенный от «воды» саммари-отчет и скачивать результат обратно в удобном расширении (PDF, DOCX, TXT) с сохранением форматирования.

---

## Главные особенности 

*  **Мультиформатный парсинг**: Асинхронное извлечение текстового слоя из файлов `PDF`, `DOCX`, `DOC`, `TXT`, `MD` и `RTF` с автоматической валидацией на пустой контент.
*  **ИИ-обработка (GigaChat)**: Использование специализированного системного промпта для суммаризации, выделения ключевых тезисов, автоматического удаления дубликатов и структурирования текста (заголовки, списки).
*  **Динамический экспорт отчетов**: Генерация файлов `PDF` и `DOCX` на стороне сервера на лету с автоматической конвертацией переносов строк в параграфы и теги верстки.
*  **Современный UI**: Минималистичный и отзывчивый интерфейс на базе **React 19** и шрифта Inter, оптимизированный под быструю загрузку файлов методом Drag-and-Drop.

## 🛠 Ключевые архитектурные решения (Middle Бэкенд-маркеры)

### 1. Безопасная интеграция с LLM и SSL-сертификация
Бэкенд интегрирован с GigaChat API с соблюдением требований безопасности. Взаимодействие со шлюзом защищено с использованием доверенного корневого сертификата Минцифры (`russian_trusted_root_ca.cer`), подключаемого через `ca_bundle_file` напрямую в клиент SDK. Это предотвращает ошибки SSL-рукопожатия на российских серверах без отключения валидации трафика.

### 2. Верстка документов и кириллическая интерполяция в PDF
Стандартные библиотеки генерации PDF (например, ReportLab) падают или генерируют случайные символы при попытке напечатать кириллицу. В данном проекте эта проблема решена на уровне инфраструктуры:
* Реализована динамическая регистрация шрифта **DejaVuSans.ttf** через `pdfmetrics.registerFont`.
* Построен конвейер сборки документа `SimpleDocTemplate` с кастомными стилями, фиксированным межстрочным интервалом (`leading = 14`), размерами полей (20 мм) и парсингом текстовых блоков в абзацы `Paragraph`.

### 3. Эффективная работа с I/O и памятью
* Вместо удержания тяжелых бинарных файлов в оперативной памяти бэкенд использует изолированные временные файлы операционной системы через `tempfile.NamedTemporaryFile`.
* Все временные файлы гарантированно удаляются из системы в блоке `finally` сразу после завершения парсинга (`os.unlink(tmp_path)`), что исключает утечки дискового пространства при высокой плотности запросов.
* Каждому генерируемому для пользователя файлу присваивается уникальный идентификатор `uuid.uuid4()`, предотвращая коллизии имен при одновременном скачивании отчетов разными пользователями.

## Стек технологий

* **Backend**: Python 3.11+, FastAPI (асинхронная обработка запросов, автоматическая интерактивная документация Swagger/OpenAPI).
* **AI / LLM Integration**: GigaChat SDK, Pydantic v2 (валидация схем данных запросов).
* **File Processing**: `pdfplumber`, `python-docx`, `reportlab` (PDF генерация с поддержкой кастомных TTF-шрифтов).
* **Frontend**: React 19, Vite (сверхбыстрая сборка приложения), React Icons, FontAwesome 6.
* **Code Quality**: ESLint 9+ с плоской конфигурацией (`eslint.config.js`).

## Инструкция по локальному запуску

### 1. Настройка и запуск бэкенда (Python)
1. Установите зависимости:
```
pip install fastapi uvicorn gunicorn python-multipart gigachat pdfplumber python-docx reportlab pydantic
```
2. Укажите ваш API-ключ GigaChat в файле `main.py` в поле `credentials`.
3. Запустите сервер:
```
uvicorn main1:app --reload --port 8000
```
*Интерфейс Swagger API будет доступен по адресу `http://localhost:8000/docs`.*

### 2. Настройка и запуск фронтенда (Node.js)
1. Установите зависимости:
```
npm install
```
2. Запустите проект в режиме разработки:
```
npm run dev
```
*Приложение откроется на порту `http://localhost:5173` или `http://localhost:3000` (в зависимости от настроек Vite).*
